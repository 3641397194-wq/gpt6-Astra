## 描述

冷咖啡是一款面向桌面与移动端的 OpenAI 兼容 API 客户端。连接冷咖啡付费 API 中转，或添加其他兼容服务商，填写你自己的 API Key，即可读取模型、流式对话、管理本机会话并在手机上整理结果。

移动工作台提供六类入口：

- REA 逆向分析
- 红队渗透
- API 审计
- 游戏客户端研究
- 样本与数字取证
- 证据报告

你可以提交目标、主机、接口、日志、样本说明或图片，实时查看结构化结果，停止任务，复制或分享报告。实际本机工具、文件处理和长时间任务仍由桌面工作台负责；手机端负责连接中转、提交任务和整理结果。

Key 只保存在设备的 Keychain 中。应用不会把 Key、签名材料或本机路径写入公开仓库。请求只发送到你选择的服务商；模型、额度、计费和隐私规则以服务商实际说明为准。

冷咖啡提供付费 API 中转、独立闭源本机工作流和定制服务。需要开通、售后或定制方案，请通过应用内社区入口联系管理。
