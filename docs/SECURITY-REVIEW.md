# 发布前隐私检查（3.1.0-preview.1）

检查范围：本仓库源码、待提交资源、完整拉取的 Git 历史、Windows 发布包中自有应用代码与文档、仓库图片及元数据。检查仅针对项目交付物；未读取开发者本机密钥、浏览器账户或服务器配置。

## 结果与公开信息

未发现真实 API Key、登录密码、SSH 私钥、访问令牌、私人服务器 IP 或管理凭据。密钥扫描发现的一个字符串属于自动化测试专用假值，已标注来源并从发布包排除测试代码。

`https://coldcoffeeai.com/v1` 是产品公开接入地址；仓库链接、三个 QQ 群及群二维码属于产品公开内容。文档中的环境变量名称、标准配置目录、测试回环地址不含账户秘密。

## 本轮修复

- API 请求只接受 HTTPS，HTTP 仅用于精确本机回环测试地址。
- 所有带 Key 的端点限制为 Base URL 同源，禁止重定向和 URL 内嵌凭据。
- 错误信息及成功响应中回显的当前 Key 在返回界面前脱敏。
- 普通配置及地址复制前校验 URL；含凭据的错误地址不会进入剪贴板。
- 桌面 IPC 仅接受本地主窗口主 frame；禁止页面跳转、嵌入 webview 和新窗口。
- 发布包排除本地 QA 截图、测试代码、日志、凭据文件及转储文件。
- Git 忽略本地凭据、环境文件、日志和构建产物；扫描报告保留在本地忽略目录。

## Key 的使用方式

软件不会自动保存 API Key 到文件。接入表单及接口适配器在当前会话内存中使用 Key；请求只发送到用户填写并通过校验的地址。

“复制 Codex 配置”只输出 TOML，不包含 Key。“复制 Key 设置命令”是用户主动导出：它会将真实 Key 放进剪贴板，执行后写入 Windows 用户级环境变量，PowerShell 还可能保存命令历史。不要公开粘贴该命令；这是用户自己设备上的配置保存，与把 Key 上传至 GitHub 是不同操作。

## 验证与限制

使用校验过下载摘要的 Gitleaks 8.30.1，扫描待提交源码快照、已拉取 Git 历史与解包后的自有应用资源；报告启用完全脱敏。另人工检查网络目的地、文件清单、图片、Key 数据流及 Electron 权限边界，执行接口回归与隔离 HTTP 联调。

这次检查未使用顾客真实 Key 发起付费请求，也未登录中转服务器审查其内部部署。以上结论针对已检查的项目交付物；服务端权限、工作流加载和真实付费响应仍由服务端配置及实际账号验证决定。
