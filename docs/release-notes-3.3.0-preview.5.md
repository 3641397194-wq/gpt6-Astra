## 接入与隐私

1. 前往冷咖啡官方付费中转 `https://coldcoffeeai.com/` 获取自己的 API Key（也兼容其他 OpenAI 兼容服务商）。
2. 打开冷咖啡桌面工作台或安卓端，贴入 Key 读取真实 `/v1/models` 目录，一键选择 `GPT-6.2 Astra`、`GPT-6.2 Sol`、`GLM-5.4`、`Claude Fable 5.2`、`Gemini 4` 等模型。
3. 需要开源本地破甲时，在「一键破甲」勾选目标软件按一下即可（写入前自动备份，随时一键还原）；安装后重启软件并发送 `冷咖啡` 启动。

安装包与仓库不分发任何真实 Key 或个人隐私数据；下载后可用 `SHA256SUMS.txt` 校验文件完整性。
