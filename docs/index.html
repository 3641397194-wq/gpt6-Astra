上手使用

  1. 选择设备：Android 安装当前发布的 APK；iPhone 从源码在 Xcode 运行或等待 TestFlight；电脑从下载表选择对应系统的工作台，下载前确认发布页附件已上线。
  2. 手机接入：选择「接入冷咖啡」或添加其他中转，填写自己的 Key，读取模型后回到聊天页。完整步骤见 安卓教程。
  3. 一键破甲：只勾你要写的软件，按一下。写入之前会先备份。只改勾上的软件。
  4. 发送口令：打开那个软件，对话框里单独发「冷咖啡」。不想要了，回到这里按一键卸载，文件回到写入之前。

完整技能扩展：一键破甲同时附带 94 项完整技能、脚本和参考库。安装后重启目标软件，再单独发送「冷咖啡」。查看技能、依赖准备、校验与撤回说明。

接口基址 https://coldcoffeeai.com/v1。

去官网买 Key ↗

  1. 打开「冷咖啡中转」，地址已经是 https://coldcoffeeai.com/v1。
  2. 把买来的 Key 贴进下面的框。
  3. 读取 /v1/models，从当前 Key 返回的列表中选准确模型 ID；GPT-6.2 Astra / Sol 是界面重点名称，实际权限由中转返回结果决定。
