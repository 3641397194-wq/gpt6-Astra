上手使用

  1. 打开软件：Windows、macOS、Linux 都用 3.2.0-preview.3。macOS 按 Apple 芯片或 Intel 选择对应安装包。
  2. 一键破甲：只勾你要写的软件，按一下。写入之前会先备份。只改勾上的软件。
  3. 发送口令：打开那个软件，对话框里单独发「冷咖啡」。不想要了，回到这里按一键卸载，文件回到写入之前。

完整技能扩展：一键破甲同时附带 94 项完整技能、脚本和参考库。安装后重启目标软件，再单独发送「冷咖啡」。查看技能、依赖准备、校验与撤回说明。

一键破甲可以一次勾选十五个 AI 模型入口（11 个模型席位和 4 个本地 Agent 工作流）。只写勾上的，按下表顺序扫描、备份、安装和校验。

工具箱

IDA Pro 9.x 简体中文界面来自 ida-zh-cn。复制 ida_zh_cn.py 和 zh_cn.json 到你的 IDA 用户插件目录。

系统默认插件目录
Windows%APPDATA%\Hex-Rays\IDA Pro\plugins
macOS~/Library/Application Support/Hex-Rays/IDA Pro/plugins
Linux~/.idapro/plugins

设置了 IDAUSR 时用它的第一段。IDA 安装目录不动。卸掉插件文件时留下你自己的 zh_cn_user.json。装好后重启 IDA，或按 Alt+F7 选中 ida_zh_cn.py。开关在 Edit → Plugins → 中文界面 开/关。

一键破甲时，能写配置的软件会带上本机 IDA 连接 http://127.0.0.1:13337/mcp。IDA 没开着，就按软件里的说明自己挂。原创工具箱另提供原生 TCP 扫描、HTTP / 网站测试、PE / ELF 分析、补丁副本和文本工具；查看能力与验收范围。
