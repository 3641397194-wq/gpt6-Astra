上手使用

  1. 选择设备：Android 安装 APK；iPhone 从源码在 Xcode 运行或等待 TestFlight；电脑下载 3.3.0-preview.1 对应系统的工作台。
  2. 手机接入：选择「接入冷咖啡」或添加其他中转，填写自己的 Key，读取模型后回到聊天页。完整步骤见 安卓教程。
  3. 一键破甲：只勾你要写的软件，按一下。写入之前会先备份。只改勾上的软件。
  4. 发送口令：打开那个软件，对话框里单独发「冷咖啡」。不想要了，回到这里按一键卸载，文件回到写入之前。

完整技能扩展：一键破甲同时附带 94 项完整技能、脚本和参考库。安装后重启目标软件，再单独发送「冷咖啡」。查看技能、依赖准备、校验与撤回说明。
