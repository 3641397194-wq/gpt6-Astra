# 冷咖啡工作台 3.2.0-preview.5

**Windows 本机验收已完成，跨平台发布由 GitHub Actions 执行。** 本轮在 Windows 完成本地构建与验收，macOS arm64 / x64 与 Linux x64 在同一套检查通过后构建。仓库主页的 `.5` 下载入口对应本版本 Release。

## 更新

- 新增冷咖啡 DeepSeek Harness 原生插件：冰晶动态开屏、整个官方 Web 界面的冰蓝皮肤、独立月夜工作空间壁纸，以及右下角助手面板。
- 助手整合六个现有研究工作流：Web 与接口安全检查、API 与身份权限、分阶段任务编排、REA 逆向与样本分析、源码审计、证据整理与报告。复用既有 REA 与 reverse-skill 资源，原启动词和完整欢迎词保持原样。
- 工作台增加「安装到 DeepSeek」与「检查插件」入口。插件资源和 Cordis 配置加入既有备份、安装、核验与恢复事务。
- 区分技能已安装、工具已注册、REA 实际成功调用、Harness 已接收和任务完成；任务记录跟随真实会话事件，模型或工具错误保留实际状态。
- 改善激活输入焦点、轮询期间表单状态、断线后提交恢复、面板收起焦点和窄屏布局；全局皮肤、背景强度与动画均可切换。
- 整合冷咖啡付费中转、全部社群和收费本机定制说明；桌面外链允许列表补齐官网与现有 Telegram 入口。
- 补齐打包排除规则，过滤预览会话文件、DPAPI 凭证文件、临时备份和开发截图，避免把本机预览状态混入发行资源。
- 文件核验逐项报告缺失、权限或占用错误与相对路径；保留严格的写后校验和事务恢复，避免单个读取异常中断整份诊断。
- 中英文 README、文档主页及插件说明新增实际 Harness 截图、现有技能映射和验收范围。

## 已验证与发布范围

- 默认安装器首次向全新隔离目录执行完整安装，11870 个文件逐项核验通过；包含 10 个原生插件文件（含完整欢迎词）及 Cordis 的 REA / 冷咖啡插件双入口。后续 Windows 复测发现至少两份上游 Markdown 资料在写入后被外部移除，完整核验如实失败；具体处理来源待查，插件本体与原词包的 99 项检查通过。
- 官方 `0.2.1-rc.2` Web runtime 已完成真实 Cordis 注入与界面检查：开屏、助手、皮肤切换、壁纸、动画、社群入口和窄屏显示。界面检查过程没有模型请求。
- 六个工作流映射到独立预览目录中实际安装的技能；完整原欢迎词的文本和 SHA-256 保持一致。
- 原生会话接口检查实际创建 Harness 会话并收到 `accepted: true`。验证进程未配置模型 API Key，测试任务随后以缺少凭证的错误结束，界面保留对应错误记录。
- 本轮 REA 观测为工具已注册、`connected: false`。成功的真实 REA 工具调用、完整模型响应及六类研究任务成果仍待实测。
- 官方独立 Desktop 发行包的完整启动链、macOS / Linux 构建与安装包验收，均留待后续对应环境验证。

这些检查分别验证安装、界面和会话接入；任务完成与研究结论仍以对应会话和工具的实际证据为准。详细用法见 [DeepSeek Harness 插件说明](DEEPSEEK-PLUGIN.md)。

发布前对源码、实际 Windows 软件包和三个技能包解码成员进行了隐私检查；当前分发内容中未发现实际服务凭据、本机私人路径或内部服务器信息。公开官网、三个 QQ 群和 Telegram 群/频道属于项目宣传信息，按原配置保留。
