# 完整技能扩展

冷咖啡工作台的一键破甲流程现在同时附带 **REA** 与 **reverse-skill**。不是只抽取几段提示词：两个上游的固定版本源码、技能正文、脚本、参考资料和许可证按目录完整保留，再通过独立的冷咖啡适配入口接入所选软件。

原有「冷咖啡」启动口令、完整欢迎词、原词包和三个 QQ 群保持不变。安装完成后，**重启目标客户端，再在对话框里单独发送「冷咖啡」**。

## 小白怎么用

1. 打开「一键破甲」，只勾选要安装的 AI 软件。
2. 点击「一键破甲」。原有词包和两套完整技能一并安装，写入前先保存原文件。
3. 往下看「完整技能扩展」：可展开、搜索全部技能；点「检查已安装技能」核对所选软件。版本、完整提交和许可详情查阅来源清单、完整源码或本文档。
4. 如果 REA 依赖尚未就绪，点击「准备 REA 运行依赖」，看清提示后确认。只有点击并确认，才进入依赖准备流程。
5. 重启目标 AI 软件，单独发送「冷咖啡」。REA 配置、运行时和外部工具是否可用分别看实际状态。
6. 不想用了，回到一键破甲页，勾选对应软件，点击「一键卸载」。按备份撤回，不删除用户后来新增的其他资料。

本地预览使用项目专用的合成目录，标注 **「隔离预览 · 不读取个人目录」**。预览页不自动安装，也不自动准备用户依赖。

## 安装了哪些东西

所选软件的数据根下增加独立目录：

```text
<所选软件的数据根>/
├─ .coldcoffee-upstream/
│  ├─ sources/
│  │  ├─ rea/              # 原样来源快照，包括技能、源码与许可证
│  │  └─ reverse-skill/    # 原样来源快照，保留全部内部相对路径
│  └─ runtime/
│     └─ rea/              # 与固定版本对应的 REA 运行资源
└─ .coldcoffee-history/    # 安装前后文件与内容校验记录
```

客户端能识别的技能位置增加独立适配入口，指向上述完整来源，而不是把大量正文复制进欢迎词。REA 与 reverse-skill 使用独立命名空间，避免互相覆盖或改写原有冷咖啡词包。

reverse-skill 的 `skills/` 与 `CTF-Sandbox-Orchestrator/` 保持原来的相对位置，因此跨目录引用、脚本入口和参考资料继续可解析。原始 README、版本文件、插件配置、依赖清单、测试与许可证也随来源保留。

REA 的客户端连接按该客户端支持的配置方式适配。界面会明确区分自动写入的连接和需要手动接入的模式；连接配置存在，不等于 REA 服务已启动或目标客户端已加载。

- **DeepSeek 官方 Harness：**使用 `$DSH_HOME/cordis.patch.yml` 的 Cordis 插入补丁；stdio 配置包含 `serverName`、`transport`、`command` 和 `args`。字段与路径依据公开的 [DSH 0.2.1-rc.2](https://registry.npmjs.org/@deepseek-ai/dsh/-/dsh-0.2.1-rc.2.tgz) 及 [MCP 客户端同版本](https://registry.npmjs.org/@deepseek-ai/dsh-mcp-client/-/dsh-mcp-client-0.2.1-rc.2.tgz) 核对。
- **ZCode：**使用 `cli/config.json` 中的 `mcp.servers`，传输类型为 `stdio`。依据官方 [MCP 指南](https://github.com/zai-org/ZCode/blob/main/apps/zcode-cli/docs/usage/07-mcp.md) 和 [配置路径指南](https://github.com/zai-org/ZCode/blob/main/apps/zcode-cli/docs/usage/03-config.md)；已有明确禁用设置时先报告原因。
- **Grok：**完整技能、源码和 REA 程序随包保留，MCP 采用所附命令手动接入。不同 Grok 客户端使用不同配置格式，安装器不套用 Codex 的配置文件。

## REA 运行时和外部工具

REA 6.7.0 的 Node.js 要求为：

```text
^22.19.0 || ^24.11.0 || >=26.0.0
```

源码快照与官方运行资源独立保存，依赖按固定版本准备。准备失败会返回真实错误和缺失项，不把「文件复制成功」显示成「工具链全部可用」。

**技能完整安装，不代表所有第三方软件都已安装。** IDA、Ghidra、JDK、Frida、jadx、radare2、Burp Suite 等仍按任务需要和上游清单准备。商业软件、需要图形操作或用户自身配置的外部工具，保留相应接入说明，不冒充已经装好。

reverse-skill 自带工具发现、平台路由、按需自举与校验脚本；这些脚本完整保留。安装流程不自动执行全部工具安装、不自动启动所有服务，也不后台执行分析任务。

## 备份、校验与撤回

- **全量备份：**写入前记录来源、适配入口、运行资源及涉及的客户端配置。大文件内容使用 `.coldcoffee-history` 的去重内容块保存，保留安装前后校验依据。
- **逐项核对：**区分内置来源清单与实际安装结果，核对真实落盘文件；界面显示技能数、文件数与校验状态。
- **可重复安装：**相同内容不重复改写；固定提交防止上游移动分支导致静默变更。
- **可撤回：**卸载按本次安装的备份恢复。安装之后用户修改过同一文件时，先报告冲突，不静默覆盖。
- **状态分开看：**技能已落盘、REA 连接配置、REA 运行依赖就绪、客户端实际加载是不同状态，不相互替代。
