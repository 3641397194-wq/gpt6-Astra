给 OpenCode 配一个中转

在桌面工作台的中转配置里选择 OpenCode。支持冷咖啡和自选兼容中转，沿用工作台的模型目录、配置预览与恢复流程。

  1. 填入 API 地址和自己的 Key
    选择冷咖啡或添加你使用的中转。
  2. 读取并选择模型
    使用中转返回的完整模型 ID，保留其中的服务商前缀。
  3. 检查配置并确认写入
    查看目标文件，写入前创建备份。需要撤回时可从备份恢复。

OpenCode 接入随本次桌面开发预览提供，下载区的 3.3.0-preview.3 安装包尚未包含该入口。
