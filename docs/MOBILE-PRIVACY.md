# 冷咖啡手机端 · 数据与隐私

适用版本：`3.3.0-preview.3`。本页说明 Android 与 iOS 客户端的数据边界，不替代你选择的 API 服务商的隐私与计费规则。

## 什么留在手机

| 数据 | 用途与处理 |
|---|---|
| 服务商名称、API 基址和模型选择 | 用于找到你配置的接口与模型，在应用资料中保存。 |
| API Key | 用于向你选择的 API 服务商鉴权。Android 使用 KeyStore 相关密钥加密，iOS 使用 Keychain；界面重新打开时不回显完整 Key。 |
| 会话、工作台记录与界面状态 | 用于本机历史会话、研究结果和恢复使用位置，保存在应用自己的资料空间。 |

Key 与会话是不同类别的数据。查看和分享设置时，应继续检查导出内容，避免把聊天中的私人资料当作普通配置传播。删除应用或清除应用数据会影响本机资料，重装前保存需要保留的内容。

应用不内置作者的运行 Key、GitHub 登录凭据、服务器管理密码或顾客凭据。APK 中的官网地址、公开 API 基址、QQ群号与公开社群链接属于产品接入和宣传信息。

## 什么会发给服务商

发送模型请求时，应用会把本次请求需要的模型 ID、对话上下文、工作台输入和请求参数发送到你选择的服务商，并使用该服务商对应的 Key 鉴权。读取模型列表也会向所选服务商发起请求。

移动工作台的文本日志、配置片段、目标、接口和输出要求会作为用户主动提交的请求内容发送给当前服务商。iOS 选择文件时会在本机生成文件名、大小和 SHA-256；文本文件只附带有限预览，二进制文件由桌面端继续处理。

切换到其他中转意味着由该中转处理请求。冷咖啡客户端提供连接能力，不会替第三方服务商保证数据保留规则、价格或可用性。

选择停止生成会尝试取消手机端的进行中请求。服务商已经接收的内容与已经产生的费用，仍按其规则处理。

## 社群、官网和外部链接

打开冷咖啡官网、Telegram 或其他公开入口时，会跳转到系统浏览器或对应应用。是否登录、是否加入群、是否购买，由用户在外部页面自行完成。

QQ群二维码使用作者指定的公开宣传图片。当前仓库没有经过确认的微信二维码，所以微信咨询通过 QQ 群联系管理获取，不从私人微信资料中提取或猜测。

## 本地保护与边界

- 使用 Android KeyStore 或 iOS Keychain 和应用私有资料空间保护本机保存的 Key。
- 公开服务默认使用 HTTPS，并保留系统 TLS 证书校验。
- 应用界面来自随包本地资源；不把原生桥暴露给任意外部网页。
- 配置分享排除完整 API Key；诊断信息避免输出 Key 和鉴权头。
- 发布源码和构建内容排除本机凭据、签名材料、调试日志、私人截图和运行资料。

这些措施降低意外泄露风险，不意味着已经获得设备系统权限的其他程序也无法读取应用运行时数据。请同时保护设备、锁屏与自己的服务商账号。
