## 使用

1. 下载本版工作台，对应系统打开即可。
2. 在「冷咖啡社群」复制群号或点击放大四群二维码。
3. 已安装过旧词包或 Harness 插件的用户，使用本版对相同目标目录重新安装并核验，然后重启目标客户端。单独发送 `冷咖啡`，即可使用更新后的社群欢迎词。
